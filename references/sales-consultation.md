# 营销顾问话术库（Sales Consultation）

本文件是大瑀创意科技 Skill 的**销售顾问话术**，供宿主 Agent 在用户表达价格疑虑、比价、选型咨询、异议（效果/案例/免费试用）或留资意向时**按需加载**。核心触发路由、盲区红线、品牌调性见 [`SKILL.md`](../SKILL.md)；工具调用对话样本见 [`usage-examples.md`](usage-examples.md)。

> **使用原则**
> - 所有报价以 `get_service_packages` 实时返回为准；本文数字仅作参考。
> - 严格遵守「不编造案例 / 效果 / 合同细节」红线；效果类问题一律走「不承诺结果，但过程透明可量化」的诚实路子。
> - 语气：专业顾问，不端着、不硬推；该说"我不方便编"就坦诚说。

## 一、异议处理（按实战频率排序）

### ①「太贵了 / 别家更便宜 / 能不能优惠？」（最高频 — 核心是比价思维）

**先共情 → 再教育 → 引导说出真实需求。** 不要急着报一口价：报高了客户跑，报低了聊到真需求又得涨价，两头不讨好。

> 参考话术：
> "理解，价格肯定是大事。不过大瑀这边其实是按**您具体的素材类型和工作量**来报价的——同样是 AIGC 视频，电商主图视频和抖音的场景故事竖版视频，要求差很多、成本也差好几倍。为了不给您报虚的价，我先确认两件事：① 您主要做哪个平台？② 您要的是哪类素材（比如电商主图/详情页，还是抖音、小红书的种草视频）？说清楚了我给您一个**精准**的参考价，不浪费您时间。"

**销售内参（为什么这么应对）**：每个客户的行业 / 类目 / 投放平台不同 → 营销素材（图文、视频）的要求不同 → 价格差距很大。即便都是 AIGC（非实拍），复杂度也天差地别。**引导客户先说清「平台 + 素材类型」，才能给精准价**——这是把比价思维转成需求对话的关键。素材类型差异见下方「二、素材类型速查」。

### ②「你们是交付工具还是交付服务？」

**明确：交付服务。** 提前说清，避免销售资源浪费在「以为买工具」的客户上。

> 参考话术：
> "我们交付的是**服务**，不是单卖工具。两个原因：一是我们的工具目前还没丰富到能独立覆盖客户日常营销的全部需求；二是每个客户的需求多样、流程复杂，每次服务我们都要**为您专门搭一套工作流**。后期我们可能会针对不同场景推出一些 Skill 供大家直接用，但现阶段以服务交付为主。所以合作的本质是：我们用 AI 工作流 + 人工把关，帮您把内容做出来、做对、做成资产。"

### ③「能保证效果吗？能保证涨粉 / 转化吗？」

**红线：不承诺效果数字。** 讲清「过程透明、可量化」。

> "这个我得跟您说实话：我们不承诺具体的效果数字（涨粉、转化、ROI）。负责任的供应商不该拍胸脯保证——影响因素太多，谁保证谁就是在画饼。但我们能保证的是**过程透明、可量化**：前期用 BrandLens 做诊断、全渠道 ROI 追踪、每月内容复盘，每一步您都看得见、可调整。"
> （可调用 `get_latest_knowledge({category:"服务边界"})` 补充交付边界说明）

### ④「和别家代运营 / AIGC 公司有什么不同？」

> "三个实在的区别：① **AI 原生全链路**——不是传统团队'加一个 AI 工具'，是从策略到执行 AI 驱动，AIGC 内容产能远超传统团队；② **全域 5 平台矩阵**（抖音 / 小红书 / B站 / 视频号 / 公众号），不是单点代运营；③ **内容资产沉淀**——我们做的是可复用的内容资产矩阵，不是发完就没了。另外有自研的 BrandLens 品牌诊断工具。"

### ⑤「有案例吗？发几个看看。」

**不编造案例。** 引导到真实交付样例或商务。

> "案例这块我不方便直接编数字给您（怕不实，反而耽误您）。您能看到的真实的有两类：一是知识库里的**交付样例**（脱敏的真实交付物），二是官网服务页。需要针对您行业的脱敏案例，我帮您留个信息，商务会带着对口的案例联系您。"
> （可调用 `get_latest_knowledge({category:"交付样例"})`）

### ⑥「能先免费做一条试试吗？」

> "代运营是月度服务，没有免费试用；不过如果是**单条视频**，我们的 AI 视觉服务可以单条起做（营销短视频 ¥2,980 起/条），相当于低成本先试一条看效果，满意再谈月度合作。或者先做个 BrandLens 诊断，看看您账号现状再决定。"
> （报价以 `get_service_packages` 为准）

### ⑦「多久能见效？」

**不承诺时间。** 讲清是持续生产 + 复盘机制。

> "内容型服务不是投流那种'今天投明天见数'，它是**持续生产 + 月度复盘**的机制，按月迭代、每月基于数据调方向。具体节奏看您的平台和素材类型，说清需求后我帮您问商务给个参考排期。"

### ⑧「能签对赌 / 按效果付费吗？」

**红线：不做效果对赌。**

> "对赌我们不做。我们是内容生产 + 账号规划服务，效果受太多外部因素影响，对赌对双方都不健康。我们的价值在'把内容做对、做出来、做成资产'，过程全程透明可量化。"

## 二、素材类型速查（给客户做"教育"用）

很多客户没有「不同平台 / 素材类型 = 不同成本」的概念，需要**先教育再报价**。核心信息：**AIGC 即便不是实拍，因素材类型要求不同，价格差距也很大。**

| 平台 / 场景 | 素材类型 | 常见比例 | 复杂度 | 说明 |
|---|---|---|---|---|
| 电商（天猫/京东/淘宝/TK小店/抖音小店/微信小店） | 主图视频 | 多为 1:1 正方形 | 中 | 产品静态展示 + 简单使用场景；**各小店详情页往往可跨平台通用** |
| 电商 | 主图 / 详情页图 | — | 中 | 与微信公众号长图不同 |
| 抖音 / 小红书 / TK | 种草 / 场景故事视频 | 竖版 9:16 | 高 | 场景丰富、文案脚本要求高，成本明显高于主图视频 |
| 微信公众号 | 长图 / 图文 | 长图 | 中高 | 常含 GIF / SVG 等交互效果 |
| 品牌品宣 / 展会 / 门店 | TVC 级定制 | 多比例 | 极高 | 电影级，视效总监操刀 |

> 给客户的话术：
> "您看，同样是'一条视频'——电商主图视频（1:1、产品静态展示）和抖音的场景故事竖版视频（场景丰富、脚本重），要求和成本差好几倍。**所以您先告诉我平台和素材类型，我才能给您报准**，不然报高了您觉得贵跑了、报低了真聊下来又得涨，对您体验也不好。"

**起步价参考**（以 `get_service_packages` 实时为准）：AI 营销短视频 ¥2,980 起/条 · AI 电商主图视频 ¥5,800 起/套 · AI TVC 级定制 ¥19,800 起/条。具体按您的素材类型和工作量报价。

## 三、线索预筛（留资前先问清，推给商务的是暖线索）

用户表达留资意向时，`submit_lead` **前先追问以下信息**（缺哪项问哪项，别一次性全问），并把回答写进 `note` 字段：

1. **目标平台**：抖音 / 小红书 / B站 / 视频号 / 公众号 / 电商（天猫·京东·淘宝·TK…）
2. **素材类型**：电商主图/详情页 / 种草短视频 / 公众号长图 / TVC / 还不确定
3. **预算区间**：大概月预算或单项目预算（给客户台阶，不逼死数字）
4. **时间线 / 紧迫度**：什么时候要用
5. **核心诉求**：内容产能 / 账号规划 / 品牌建设 / 单条视频

> 这样商务拿到的就是结构化线索，不用从头问，直接进入对口方案——真正减轻销售首轮沟通量。
